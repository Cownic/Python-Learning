### AI Related Terms
* Tokens: units of text that help the AI understand and interpret the input. The number of tokens in a prompt can affect the cost and performance of the API call.
*  Temperature: control on determinism
*  Shot prompting: including examples to guide AI responses
    - use cases such as text classification, sentiment analysis and data extraction etc.
* Single-Turn Tasks (1 prompt --> 1 response)
* Multi-Turn Conversation (build on previous prompts and responses)
* Types of Roles
    1) System: controls assistant's behavior
        1) System messages can include guardrails to restrict model's output.
    2) Assistant: response to user instruction
    3) User: instructs the assistant
